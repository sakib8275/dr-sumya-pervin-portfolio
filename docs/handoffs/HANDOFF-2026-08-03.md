`workers/digest/` (untracked) gets the **shape right**: crons `30 8 * * 0-3,6` +
`30 10 * * 0-4,6` hit exactly the DCIMCH (08:30 UTC) and Alliance (10:30 UTC)

**Bugs to fix before it can run (found against the live schema):**

1. **Wrong column names** — it selects `name, phone, ... WHERE date = ?`, but the
   real schema is `patient_name, patient_phone, appointment_date, service, notes,
   status, created_at`. It would fail at first fire (verified: `SELECT name …` →
   `no such column: name`).
2. **Missing import** — `EmailMessage` must come from `import { EmailMessage } from
   "cloudflare:email"` (or build MIME via the `mimetext` package); the bare global
   is undefined in module workers.
3. **UTC date bug** — `new Date().toISOString()` is UTC; Dhaka is UTC+6. Use the
   same Dhaka-date logic as `functions/lib/schedule.js` (extract a shared helper or
   duplicate the ~5 lines; F4 is the reference implementation).
4. **Sender mismatch** — scaffold sends from `noreply@drsumyapervin.com`; the plan
   (HUMAN-TASKS Task 13) creates **`digest@drsumyapervin.com`**. Pick one, create it
   in Email Routing, use it consistently.
5. **"Unknown Chamber" branch sends email** — on an unexpected cron it should log
   and return, not email.
6. No tests. F8 spec wants: stubbed D1 + captured payload, per-chamber filter,
   Dhaka/UTC edge, empty-list body.

Then the F8 spec itself: unit tests → `wrangler deploy` from `workers/digest/` →
