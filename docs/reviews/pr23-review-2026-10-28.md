## P3 — The contrast test assumed white text — REAL, FIXED (`2edea22`)

**Finding.** `tests/contrast.test.mjs` fell back to `#FFFFFF` whenever a rule's `color` was missing or was not a hex literal. Its comment said the hover rule "inherits" the base colour, but the code never read the base rule.

**Reproduced.** Changing the base rule to `color: var(--ink)` gives a real contrast of 2.92:1. The test still passed, because it computed white on `#0E7A40`.

**Fix.** The test now:
- resolves hex literals and `:root` tokens (through the file's own `token()`), and fails on anything else;
- has the hover rule use the base rule's text colour unless it sets its own.

**Mutation-checked.** Each of these now fails the test:
- base `color: var(--ink)`: 2.92:1;
- hover `color: #1C2233`: 2.39:1;
- `color: currentColor`: unresolvable.

## P3 — The scroll padding was fixed in px while two bars grow with the font size — REAL, FIXED (`09f737c`)

**Finding.** The price tabs and the phone bottom bar are as tall as their text: 31px of padding and rule, plus one line. The reviewer worked out from the CSS that a 24px default font would outgrow the px padding by a few pixels. That is a partial overlap, so 2.4.11 Minimum still held.

**Reproduced.** A new e2e test sets `html { font-size: 24px }`, the same as a browser default of 24px, because `html` carries no font size of its own. It then compares the computed `scroll-padding` with the measured bars. Before the fix:

| Width | Padding needed | Padding | Gap |
|---|---|---|---|
| Phone, bottom bar | 68.2px | 64px | 4.2px short |
| Phone, header + tabs | 129.7px | 128px | 1.7px short |
| Desktop, header + tabs | 143.7px | 142px | 1.7px short |

**Fix.** The bar-dependent terms are now `px + rem`:
- `/prices/` on desktop: `calc(119px + 1.41rem)`;
- `/prices/` on phones: `calc(105px + 1.41rem)`;
- the phone bottom: `calc(39px + 1.55rem + env(safe-area-inset-bottom))`.

At 16px these values are within a pixel of the old ones, and each still leaves about 9px of air. The new test passes at both widths.
