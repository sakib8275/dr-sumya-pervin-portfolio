# Handoff — Dr. Sumya Pervin Portfolio

## Project Overview

Single-page portfolio for Dr. Sumya Pervin, MD — a dermatologist and aesthetic medicine specialist based in Dhaka, Bangladesh. Built with vanilla HTML5, CSS3, and ES6+ JavaScript (no frameworks, no build tools). Backend is Cloudflare Pages Functions + D1 (SQLite) + R2 (images). Targets patients on mid-range Android phones (360–390px viewport) who want to book consultations.

---

## Architecture

### Hosting: Cloudflare Pages
- Static assets served from Cloudflare edge
- API lives in `functions/` directory (Pages Functions)
- Custom domain: `drsumyapervin.com` (Cloudflare-managed)

### Database: Cloudflare D1 (serverless SQLite)
- 4 tables: `admin_settings`, `appointments`, `gallery`, `contact_messages`
- Migration file: `migrations/001_schema.sql`
- Run via: `wrangler d1 execute dr-sumya-pervin-db --remote --file=migrations/001_schema.sql`

### Image Storage: Cloudflare R2
- Bucket: `dr-sumya-gallery`
- Gallery images uploaded via CMS and served at `/api/uploads/:filename`
- No disk storage — images live in R2

### Auth: JWT (stateless)
- Library: `jose` (HS256)
- Default PIN: `talhatheboss` (SHA-256 hashed, seeded in migration)
- Token stored in `localStorage` as `cms_token`, 24h expiry
- No sessions, no cookies

### Frontend
- `index.html` — D1 single-page app
- `css/style.css` — CSS custom properties design system, glassmorphism, full-width layout
- `js/main.js` — `api()` helper with auto JWT header, CMS panel, gallery render, booking form, quiz, slider, accordion, carousel

## Deploy Steps (Pending — requires Cloudflare dashboard access)

```bash
npx wrangler login

# Create D1 db & copy database_id into wrangler.toml
npx wrangler d1 create dr-sumya-pervin-db

# Create R2 bucket
npx wrangler r2 bucket create dr-sumya-gallery

# Run migration
npx wrangler d1 execute dr-sumya-pervin-db --remote --file=migrations/001_schema.sql

# Set secrets
npx wrangler secret put JWT_SECRET
npx wrangler secret put SITE_SECRET

# Deploy
npx wrangler pages deploy .
```

Then in Cloudflare Dashboard → Pages → connect `drsumyapervin.com` domain.

## Known Issues / Gotchas

- **`.wrangler/` is gitignored** — local wrangler dev state is not committed. Run `wrangler d1 execute ... --local --file=migrations/001_schema.sql` to seed the local dev DB.
- **JWT_SECRET must be set** before deployment — without it, login returns 500. Set via Cloudflare dashboard or `wrangler secret put`.
- **D1 migration must run before the site works** — the `_middleware.js` fallback seeder only creates a default row if the DB is completely empty, but the schema (tables) must exist first.
- **No signup flow** — only one admin PIN exists. Changeable via CMS Settings (requires current PIN). If PIN is lost, run a new D1 query to reset it.
- **Booking flow:** User still sees "Appointment Details Saved — Send to Doctor" after booking. The data is now persisted in D1 (no longer lost on cache clear), but the doctor must check the CMS to see new bookings. No push notification exists.
- **Hero gradient contrast** is inherently fragile — any change to hero gradient colors needs contrast re-verification.

- **Service worker / offline:** Would make the site work offline for returning patients on slow connections.
