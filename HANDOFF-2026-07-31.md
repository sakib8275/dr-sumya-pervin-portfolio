### Booking click path — **closed, no overlay**

The previous session's open question is answered. Real pointer clicks with default
actionability waits — no `force`, no `requestSubmit()`, no manual scrolling — succeed at
**three viewports** (508×894, 1280×800, 390×844). Each produced `POST /api/appointments` →
**201** with a distinct server id, the confirmation panel echoed the submitted name, and all
three rows were read back out of local D1 with ids matching the response bodies. Probe rows
have since been deleted.

The reported `[data-r]` interception had **two independent causes, neither a bug**, both now
documented in the playbook because both will mislead whoever writes the T7 suite:

1. `.modal-overlay` is `opacity: 0; pointer-events: none` until `.active`. The submit button
   still has a non-empty box while the modal is closed, so Playwright rates it *visible* and
   hit-tests straight through the overlay onto page content. Reproduced exactly:
   `elementFromPoint` at the button centre returns `DIV.namecard.in`.
2. `.modal-box` is `max-height: 90vh; overflow-y: auto`, so the button sits below the box's
   internal scroll fold. `page.click()` scrolls it in first; a real user scrolls the same way.

Both were checked against the settled state (`.active`, overlay `opacity: 1`, `.modal-box`
`transform: matrix(1,0,0,1,0,0)`, plus 700 ms past the 0.3 s transitions), so this is not
"animations had not finished."

## Environment gotchas — these will cost you an hour each

- **A narrow `CLOUDFLARE_API_TOKEN` is exported in the shell and shadows the working OAuth
  login.** It authenticates but has no account-level scope, so `/accounts` returns an empty
  list and wrangler fails with *"Failed to automatically retrieve account IDs"* — which reads
  exactly like being logged out. **Prefix every wrangler call with `CLOUDFLARE_API_TOKEN=`.**
- **That token was leaked into a session transcript on 2026-07-30** by a malformed presence
  check (`${VAR:-no}` prints the value). Token id `b17d8b1322d3a80ddeebb36d76ae8ba5`.
  **Rotation was requested and has not been confirmed done.** It was never written to a repo
  file and is not in git.
- **Remote D1 writes are blocked by the permission classifier.** Agents cannot run
  `wrangler d1 execute --remote` with `--file` or any mutation; the operator must run those
  with the `!` prefix. Read-only `SELECT` works.
- **Never serve this with a plain static server** — `/api/*` will 404 and the site will look
  broken in ways that are not real. Use `npm run dev`.
- **Local D1 is not production.** It lives in `.wrangler/` (gitignored) and holds a throwaway
  PIN plus probe bookings, one carrying stored XSS payloads. Delete `.wrangler/` to reset.
- **The old PIN and the original `SITE_SECRET` are in git history permanently** and stay
  compromised. Rotation, not scrubbing, was the response. Treat any reference as historical.
- **Scope discipline:** `Desktop/portfolio-astro/` and `Desktop/Portfolio/` are different
  projects. Do not report findings about them.
