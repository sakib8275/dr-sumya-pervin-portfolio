### Two fixes found and made during T6 (uncommitted)

1. **`wrangler.toml` had no `compatibility_date`.** It defaulted to *today* and outran the

2. **`public/index.html` booking form had no submit guard.** No `action`/`method`, so a submit

   would have missed it. Verified both directions: no navigation pre-hydration via click,

## Gotchas for the next agent

- **Never serve this with a plain static server.** `python3 -m http.server` / `npx serve`
  cannot run Pages Functions, so `/api/*` 404s and the site looks broken in ways that aren't
  real — and pointed at the repo root, that is what published the original leak.
  Use `npm run dev` (added this session; wraps `wrangler pages dev public --local`).
- **Local D1 holds test data**, including a throwaway local-only PIN and several probe
  bookings, one carrying XSS payloads. It lives in `.wrangler/` (gitignored) and is *not*
  production. The throwaway value is deliberately not recorded here; reseed with
  `npm run seed-pin` and a local `UPDATE admin_settings`, or delete `.wrangler/` to reset.
- **Playwright `page.route()` persists across navigations.** A stale route abort made a
  known-good success path look broken this session, which nearly read as a regression. Call
  `page.unrouteAll()` between phases.
- **`requestSubmit()` ≠ a user click.** It bypasses hit-testing. Useful to isolate harness
  problems from code problems, but it is not evidence the button is clickable — see the open
  question above.
- **A status code is not a result.** A prior session concluded `.assetsignore` "did not work"
  from 200s that were the index.html fallback. Every check this session asserts on response
  *bodies* and rendered DOM. Keep that standard.
- **The old PIN and `SITE_SECRET` are in git history permanently** and stay compromised.
  Rotation, not scrubbing, was the response. Treat any reference to them as historical.
- **`AUDIT.md` / `FIXPLAN.md` are superseded** (pre-migration Express codebase).
  `UX-AUDIT.md` / `UX-FIXPLAN.md` are partly superseded.
- **Scope discipline:** per user memory, don't volunteer findings about sibling projects.
  `Desktop/portfolio-astro/` and `Desktop/Portfolio/` are different projects.
