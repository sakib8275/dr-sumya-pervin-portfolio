## Findings worth carrying forward

- **`/api/contact` is gated but unreachable.** There is no contact form in `public/index.html`
  and no `api/contact` reference anywhere in `public/`. Only two widgets exist (login, booking).
  "Turnstile gates all three write endpoints" is true of the code and misleading about the UI —
  gating it broke nothing, and nothing tests it because nothing calls it.
- **The widget did not re-arm after `turnstile.reset()`** within 20s; a page reload was needed.
  Unresolved: this may be Cloudflare treating an automated browser as suspicious on a second
  solve, or it may affect real users, in which case someone retrying a failed booking must
  re-solve the checkbox manually instead of the widget silently re-arming. Not a blocker — the
  first attempt always works. Settle it by watching one retry in a normal browser.
- **A WAF rate-limit rule still cannot protect a `.pages.dev` hostname.** WAF rules are
  zone-scoped and that hostname is Cloudflare's. The T5 plan in `SUBAGENT-PLAYBOOK.md` assumes
  otherwise. A WAF rule only becomes effective once `drsumyapervin.com` is connected, and only
  for that hostname. This is why Turnstile was chosen; the WAF rule is still worth adding as a
  second layer afterward.

## Environment gotchas

- **Prefix every wrangler call with `CLOUDFLARE_API_TOKEN=`.** A narrow token exported in the
  shell shadows the working OAuth login and fails with *"Failed to automatically retrieve
  account IDs"*, which reads exactly like being logged out.
- **`wrangler pages deploy`, `pages secret put`, and remote D1 writes are blocked by the
  permission classifier.** The operator must run these with the `!` prefix. Reads work.
- **Local D1 starts empty.** See item 1 above — apply `migrations/001_schema.sql --local` and
  seed a throwaway PIN before any local browser test. Never use the production PIN locally.
- **`<select>` option labels differ from their values** (`chamberSelect`, `serviceType`).
  Browser automation must select by label, not value.
- **Never serve this with a plain static server** — `/api/*` 404s and the site looks broken in
  ways that are not real. Use `npm run dev`.
- **Scope discipline:** `Desktop/portfolio-astro/` and `Desktop/Portfolio/` are different
  projects.
