# Clinic logo concept study

Recommended: **01 — Signature SP**. A custom SP mark with a skin contour, paired with Dr. Sumya Pervin’s name. The full Centre descriptor is a future clinic lockup; the project lists its opening as 2027.

Open `index.html` locally to compare six concepts, switch background previews and download SVGs. No server or external resources required. `concept-board.png` is a static comparison; `01-signature-sp.png` is a transparent indigo export at 1024 × 1024.

Palette: indigo `#23336B`, ivory `#F7F3EA`, turmeric `#E0A526`. Use the logo in one colour; keep gold as an optional surrounding accent. SVGs use `currentColor` and a `0 0 100 100` viewBox. Standalone SVG defaults to black; set CSS `color` when embedding inline.

Grounding: `content/site.mjs` (name, Centre, opening); `content/pages/about.mjs` (practice and approach); `content/pages/home.mjs` (diagnosis, written plans, follow-up); `public/css/site.css` (Nil & Haldi palette). The existing `public/favicon.svg` has an SP text mark; this study explores a custom vector successor.

Concepts are original drawing proposals, not trademark clearance. The wordmark in the HTML is a typography direction using local Georgia; exported SVGs contain the symbol only. Concept 01 was installed on the website on 2026-10-04 (`content/brand.mjs`, commit `9e06825`), pending the doctor's sign-off; the other five remain alternatives. Photorealistic mockups are a later step after direction selection.
